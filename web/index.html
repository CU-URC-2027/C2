Control plane

WebSocket input and state updates. The Python control loop runs at 20 Hz independently of the UI. Only a new operator sample refreshes the 250 ms input deadline. HTTP serves images, exports, and local resources.

Camera panes

The browser decodes five received H.264 streams from the local TCP receiver. The original generated demos and HTTP snapshots are preserved. Encoding and source generation remain in the separate architecture lab.

What remains hardware work

Arm output is a preview. RC input is emulated. Battery telemetry is unavailable. Pose is a toy model. Physical GPS, actual snapshot sources, controller mapping, and rover firmware integration need hardware validation.

Development workflow

Use uv sync, then uv run python scripts/dev.py --open. Run uv run python scripts/verify.py. Read docs/ARCHITECTURE.md and docs/PORT_PARITY.md before changing control behavior.
